离线安装包手动载入指引（只需 30 秒）

  1. 下载网盘 ZIP 压缩包并解压至本地固定文件夹（请勿随意移动该文件夹）。
  2. 打开 Chrome 或 Edge 浏览器，地址栏输入 chrome://extensions/ 并按回车。
  3. 在页面右上角打开「开发者模式 (Developer mode)」开关。
  4. 点击左上角的「加载已解压的扩展程序 (Load unpacked)」按钮。
  5. 选择刚才解压出来的 HORD 插件根目录（包含 manifest.json 的文件夹）即完成载入！
