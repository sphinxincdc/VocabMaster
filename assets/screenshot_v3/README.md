## 命名规范 (Naming Convention)

所有截图与素材统一遵循语义化命名格式：

`[模块编号或前缀]-[子场景/功能]-[关键信息/词条/状态].[扩展名]`

- **模块前缀**：与所属主模块保持一致（如 `Manager-`、`阅读器-`、`网页划词-`、`复习-`、`YouTube-`、`Bilibili-`、`品牌素材-`、`金句导出-`、`导出工作台-`）。
- **子场景/功能**：清晰描述所在视图（如 `Bento仪表盘`、`查词弹窗`、`书架`、`AI翻译面板`、`视频划词`、`社媒卡片`）。
- **关键信息**：标识具体代表性词条、书籍、模板名或状态（如 `patronizing英汉释义`、`老人与海`、`AbyssMatrix`、`低对比度质量提醒`）。
